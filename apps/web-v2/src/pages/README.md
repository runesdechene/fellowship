# pages — hors de la coquille

Les écrans qui ne vivent pas dans `AppShell` (sans barre latérale ni barre du haut).

- `Unsubscribe.tsx` — la désinscription des e-mails de prospection, publique (lien des e-mails).
- `Login.tsx` — la connexion par code e-mail. Hors maquette, volontairement minimale.
- `legal/` — les documents légaux (mentions, confidentialité, CGU, CGV, charte), publics.
