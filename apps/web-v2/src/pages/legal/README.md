# pages/legal — les documents légaux

Mentions légales, confidentialité, CGU, CGV, charte : publics, hors de la coquille de l'app,
repris mot pour mot de la V1 à la bascule (lot 12). `LegalRoute.tsx` choisit le document par l'adresse, le cadre commun est `LegalFrame.tsx` ; les
faits (éditeur, hébergeurs) vivent dans `lib/legal.ts`.
