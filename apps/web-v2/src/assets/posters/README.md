# posters — les dessins des affiches par défaut

Un SVG par catégorie, nommé par son slug (`fete-medievale.svg`, `festival-metal.svg`…), exporté de
la planche Figma « 2027 — Affiches par défaut » (2704:287, validée par Uriel le 02/11/2026). Tous
tiennent dans la même boîte de 98 × 98, la zone de dessin de l'affiche.

Lus par `lib/poster-category.ts` ; la palette et la police de chaque catégorie vivent dans
`styles/2-semantic.css`. Une nouvelle catégorie demande son dessin ici, sinon elle prend « Autre ».
