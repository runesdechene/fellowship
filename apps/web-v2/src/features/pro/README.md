# features/pro — l'offre Pro

- `ProPage.tsx` — `/pro`, la page de l'offre, où mènent toutes les invitations du gratuit.
- `PlanCard.tsx` — les cartes Gratuit et Pro ; le bouton ouvre le paiement ou l'espace Stripe.
- `ReferralCard.tsx`, `useReferral.ts` — « Parraine un exposant » : le code, le lien, les filleuls
  (chantier 3, sans maquette).
- `ProFaq.tsx` — « Le coût de la route · Bientôt » et les questions fréquentes.
- `useCheckoutReturn.ts` — le retour de Stripe : bandeau et relecture bornée de l'identité.
