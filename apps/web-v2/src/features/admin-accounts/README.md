# features/admin-accounts

L'administration, liste des comptes (`/admin/comptes`), par enseigne ou par personne.

- `AccountsPage.tsx` — la page : en-tête, bascule de vue, assemblage.
- `useAccounts.ts` — charge chiffres, filtres, lignes et membres selon l'adresse.
- `AccountsStats.tsx` — les quatre chiffres.
- `AccountsTools.tsx` — recherche, filtres, tri affiché, pied de page paginé.
- `EntitiesTable.tsx` · `PeopleTable.tsx` — les deux tableaux.
- `activity.ts` — « 14 dates · 6 avis ».
