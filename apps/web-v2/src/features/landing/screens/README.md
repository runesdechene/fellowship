# features/landing/screens — les écrans de l'app, reproduits pour la landing

Chaque écran est dessiné à la taille de l'app puis réduit dans une fenêtre (`AppWindow`). Les
festivals viennent de la base ; l'exposant, ses statuts et ses compagnons de `lib/landing-demo.ts`.
Aucun n'importe une page de l'app.

- `AppWindow.tsx` — la fenêtre « flw.sh — … » et la barre latérale de démonstration.
- `DemoStatus.tsx` — inscrit, dossier envoyé, intéressé, dits par la forme.
- `CalendarScreen.tsx`, `DashboardScreen.tsx` — la bande Assistant.
- `CommunityScreen.tsx`, `WhoGoesScreen.tsx` — la bande Communauté.
- `OneClickCard.tsx`, `PdfSheet.tsx`, `HuntScreen.tsx` — la bande « Bientôt · Pro ».
